StillTime Privacy Policy

Effective date: September 19, 2026

StillTime is a fully offline Android app designed for a quiet breathing and ambient-audio experience.

Data collection and sharing

StillTime does not create user accounts, request Internet access, display ads, use analytics, or integrate advertising or tracking SDKs. The app does not collect, transmit, sell, or share personal or sensitive user data.

Data stored on the device

StillTime stores only the local preferences needed for the app experience, including ambient-audio enabled state, ambient volume, and reduced-motion preference. These settings are stored in Android app-private storage using DataStore Preferences.

Cloud backup is disabled for StillTime. The app has no server-side storage.

Security, retention, and deletion

Because StillTime does not collect or transmit personal or sensitive user data, there is no personal-data transmission or server-side retention.

Local app preferences remain on the device until the user changes them, clears StillTime's app storage, or uninstalls the app. Clearing app storage or uninstalling StillTime removes those local preferences.

Audio

The ambient audio used by StillTime is bundled inside the app and plays locally through AndroidX Media3. No audio is streamed from a server.

Third-party components

StillTime uses AndroidX libraries and AndroidX Media3 for on-device application functionality. The app does not grant itself Internet permission, so its V1 runtime has no application network access.

Children

StillTime is designed for all ages and does not collect personal information from any user, including children.

Changes to this policy

If a future StillTime version changes how data is accessed, collected, used, or shared, this policy and the Google Play Data Safety declaration will be updated before that version is published.
